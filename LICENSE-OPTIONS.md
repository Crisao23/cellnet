# License options

No license is selected automatically.

Common choices:

- **MIT** — permissive, simple attribution requirement.
- **Apache-2.0** — permissive plus explicit patent grant.
- **GPL-3.0** — redistributed derivative works remain under GPL-compatible terms.
- **No license** — default copyright applies; public visibility does not grant broad reuse rights.

After choosing, add the official text as a root file named `LICENSE`. GitHub can generate standard license text.
